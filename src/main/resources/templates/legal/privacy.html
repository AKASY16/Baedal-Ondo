03

개인정보의 제3자 제공

배달온도는 현재 회원의 개인정보를 제3자에게 제공하지 않습니다. 향후 제3자 제공이 필요해지면 제공받는 자, 목적, 항목, 보유 기간과 동의 거부 권리를 사전에 알리고 필요한 동의를 받겠습니다. 법령에 특별한 근거가 있는 경우는 예외로 합니다.

04

개인정보 처리의 위탁과 국외 이전

배달온도는 서비스 인프라 운영을 위해 AWS를, 도메인 연결과 트래픽 보호를 위해 Cloudflare를, 문의 접수와 답변을 위해 Gmail을 사용합니다. 각 수탁자는 아래 범위에서 개인정보를 처리·보관합니다.

수탁자·이전받는 자업무와 목적이전 항목국가·방법보유 기간
Amazon Web Services Korea LLC
(AWS)
개인정보 보호 안내		 서비스 서버·데이터베이스·로그·백업 인프라 운영 회원 계정, 동의 이력, 가게 정보, 서비스 이용·접속 기록 대한민국 서울 리전(ap-northeast-2)에 네트워크를 통해 전송·보관 회원 탈퇴 또는 위탁계약 종료 시까지. 백업 데이터는 설정된 보존 기간이 지난 뒤 삭제
Cloudflare, Inc.
개인정보처리방침 확인		 도메인 연결, 콘텐츠 전송(CDN)과 트래픽 보호, 접속 통계 집계 접속 IP 주소, 접속 일시, 브라우저 정보(User-Agent), 요청 주소와 응답 상태, 요청에 포함된 쿠키 미국을 포함한 Cloudflare 엣지 서버 소재 국가
이용자의 모든 요청과 응답이 엣지 서버를 통과하는 방식으로 이전		 보안 기록과 접속 통계는 Cloudflare 정책에 따른 기간 동안 보관한 뒤 삭제
Google LLC
(Gmail)
문의·정책 확인		 문의 이메일 수신·보관·전송 보낸 사람 이메일 주소, 문의 내용과 첨부 정보 미국을 포함한 Google 데이터센터 소재 국가
이메일 발송 시 네트워크를 통해 이전		 문의 처리 완료 후 지체 없이 운영자 메일함에서 삭제. 이후 Google 정책에 따른 백업·보안 보관 기간이 적용될 수 있음

AWS의 주 데이터 저장 위치는 대한민국 서울 리전(ap-northeast-2)입니다. AWS는 고객이 선택한 리전 밖으로 고객 콘텐츠를 이동하거나 복제하지 않는다고 안내합니다.

Cloudflare는 배달온도의 도메인 앞단에서 동작하므로 이용자의 모든 접속이 이 구간을 지나갑니다. 배달온도는 여기서 접속 통계를 집계하며, 이 통계에는 이용자를 개별적으로 식별하기 위한 쿠키를 사용하지 않습니다.

Google은 전 세계의 서버에서 정보가 처리될 수 있다고 안내합니다. 자세한 내용은 Google 개인정보처리방침에서 확인할 수 있습니다.

배달온도는 위 국외 처리·보관 사항을 개인정보 보호법 제28조의8에 따라 공개합니다. 문의 메일에는 문의 처리에 필요하지 않은 민감하거나 불필요한 개인정보를 기재하지 말아 주세요.

05

공공데이터·외부 API 이용

수요 점수 계산을 위해 주소 좌표 변환, 기상청 날씨, AirKorea 대기질, 공휴일 정보를 제공하는 공공 API를 이용합니다. 이 과정에서 주소 관련 코드나 주소 일부, 기상 격자, 행정구역명이 각 API 요청에 포함될 수 있습니다.

로그인 ID, 이메일, 비밀번호는 이러한 공공 API에 전송하지 않습니다. 외부 기관은 각 기관의 정책에 따라 요청 로그를 처리할 수 있습니다.

06

개인정보의 파기 절차와 방법

  1. 보유 기간이 지나거나 처리 목적이 달성되어 개인정보가 필요하지 않게 되면 지체 없이 파기합니다.
  2. 법령에 따라 보존해야 하는 정보는 다른 정보와 분리하여 해당 기간 동안 이용하지 않고 보관합니다.
  3. 전자 파일은 복구하기 어려운 방법으로 삭제하고, 출력물이 있는 경우 분쇄 또는 소각합니다.

09

로그인 세션과 쿠키

배달온도는 로그인 상태를 유지하기 위해 세션 쿠키(JSESSIONID)를 사용합니다. 이 쿠키는 회원을 인증하는 데 사용되며 광고 추적을 목적으로 사용하지 않습니다. 브라우저 설정에서 쿠키를 차단할 수 있지만, 차단하면 로그인이 필요한 기능을 이용하기 어렵습니다.
